# 待辦、已結案與臨會／專題：頁內數據統計

## 入口與範圍

- 待辦總表、已結案清單、臨會／專題工具列新增「數據統計」。同頁原生對話框，關閉回到原清單／會議；不呼叫保存、批量操作、編輯 lease 或額外雲端 RPC。
- 預設統計**目前清單的全部結果**，不受分頁及勾選影響；沿用已授權且已載入的原頁資料。總表／已結案的「同條件全部狀態」只取消 `closedMode`，保留關鍵字、最後更新日期、船舶、來源分類、部門、關注、內控和僅逾期條件。
- 會議頁沿用原關鍵字、範圍、船型；同條件全部狀態只移除狀態與未完成／已完成清單限制。整場會議與會議待辦／決議是分開的資料集，切換資料集會重設視窗內次級條件。
- 待辦資料集計實際可見派生 TaskItem，每筆一次；另納入原無涉船流程的獨立決議。缺少可判定的可見關聯只顯示缺漏提示，不從會議 metadata 重建隱藏待辦或推定完成。
- 身份／授權脈絡改變會關閉統計視窗；這不是新增權限。原草稿／保存／CAS／lease／批量 ACK 程式不變。

## 分母與日期

| 指標 | 口徑 |
|---|---|
| 完成率 | 已完成 ÷ 目前統計範圍全部案件 |
| 未結逾期率 | 未完成且有效期限早於台北今天 ÷ 同一分母；卡片另標佔未結案件比例 |
| 按期完成率 | 完成日不晚於期限的已完成案件 ÷ 完成日、期限均有效的已完成案件 |
| 逾期結案 | 完成日已晚於期限的案件；與仍未結逾期分開 |
| 平均結案天數 | 完成日－建立日的日曆天數；只納入有效且非負的期間 |
| 未設有效期限 | 空白／不合法日期均不當成逾期或準時 |
| 未結案齡 | 未完成案件按 0–7／8–30／31–90／超過90天及日期不明分組，以未完成案件為分母 |

零分母顯示「—」，不製造 0% 績效。純待辦或純已結案清單的完成率可能自然為0%／100%；要比較績效可切換全部狀態。次級日期可選建立日／完成日；重設只清統計視窗條件，不清原頁篩選。

## 歸屬、排名與趨勢

- 九面向：部門、人員、船舶、來源、分類、關注程度、完成狀態、管控標記、未結案齡。
- 人員責任＝案件追蹤窗口及有效分管／代理；會議另含負責人，單純與會者不列為責任人。部門亦含案件本身部門。分管沿用 `vesselResponsibilityIncludes`（含交接限制），不推造歷史責任歸屬。
- 部門／人員是責任案件的完成率，沿用該清單可見船舶範圍；不是個人操作次數或個人操作速度。船舶排名使用該船進度及完成日。
- 多船案件在總數只算一次；逐船排名各計一次。跨部門、人員及多選分類佔比可以超過100%，同一組內去重。不同來源分類不混合。
- 支援依件數、完成率、未結逾期件數／率、逾期結案、按期完成率排序；同值並列，未可計算排末。點排名名稱僅聚焦趨勢，不偷偷改動全頁 KPI 分母。
- 日／週／月曲線：新增事件按建立日，完成事件按有效完成日；週從星期一開始，首尾週只計區間內日期，缺期補零。缺日期單獨提示，超過366時間點明確要求縮短或改週／月。
- 趨勢僅是目前符合篩選案件的新增／完成事件，**不是歷史庫存、重新開啟次數或完整歷程報表**。
- 手機排名維持全部欄位，在排名表內左右捲動，不隱藏數值或使整個統計視窗橫溢。

## 本機驗證邊界

`npm run test:page-statistics`：計算、原頁 filter、可見單船進度、日期、重疊分組、獨立事件趨勢及會議／決議區分。

`npm run test:page-statistics-browser`：真實 `ListPanel`／`TemporaryMeetingsPage`＋synthetic fixture；經真實工具列開關統計，測試篩選、排名、趨勢、原勾選／DOM保留、原會議兩份清單，以及三頁 1280／820／390px 幾何。暫存 Chrome profile、loopback Vite 均在 finally 清理，證據留於 repo 外 Hermes scratch。

這是本機真實 UI＋測試資料，不是正式環境驗證。沒有新增 SQL、資料庫欄位、遠端寫入、發布或試用站。既有清單選取 PDF 與剛完成的數據分析頁保留原行為。
