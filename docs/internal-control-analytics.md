# 內控異常：數據統計

## 操作

- 上方原有篩選不變。統計沿用同一個已授權、已依條件篩選的案件集合，不另讀其他資料。
- 五項指標改為緊湊排列；六個既有分布改為窄版總覽，最多顯示前三項。按「查看排名」可切換該面向並查看全部項目。
- 分析面向：船舶、船型、重要程度、事項分類、涉及部門、報告來源、設備故障細項、結案狀態。
- 排名按件數由多到少；相同件數並列名次。點名稱查看該項趨勢，再點一次或按「恢復全部」回到目前篩選的全部案件。
- 趨勢可按日、週、月顯示。更改上方篩選或分析面向後，清除前一次的趨勢單項選擇。
- PDF沿用畫面的分析面向、期間單位及趨勢對象；原案件清單、Excel匯出、編輯、結案、權限及保存流程不變。

## 統計口徑

1. **佔比的分母固定為目前篩選的案件總數**，不是所有案件、船舶總數或所有部門提及次數。顯示一位小數，四捨五入合計可能略有差異。
2. 單值面向每案計一次；部門是多值面向，同案同部門只計一次，可計入不同部門。部門顯示「涉及率」，合計可能超過100%。
3. 未填部門／細項等仍保留明確分組；非「設備故障」案件的設備面向列為「不適用（非設備故障）」。船舶用ID分組，不因顯示名稱相同而合併。
4. 上方日期仍是**報告日期篩選**，先決定案件母體。趨勢中的新增依報告日期、結案依目前已結案件的結案日期計數；已重開案件不把殘留結案日期計作目前結案。
5. 圖表只計所選日期區間內的事件，所以圖中的結案數可以不同於已結案指標；它不是全站期間結案工作量，也不是完整結案／重開歷史。
6. 未指定日期邊界時，依該篩選集合中的有效報告／結案日期自動取界。點排名看單項時保持同一時間軸；空白期間補0。週以週一開始，日期分桶用UTC日期運算，不隨瀏覽器時區移動。
7. 缺漏／無效日期（包括早於報告日期的結案日期）不納入對應曲線，顯示排除件數。無資料時不製造數值。
8. 超過366個時間點時，明確要求縮短區間或改用較粗單位，不靜默截斷。
